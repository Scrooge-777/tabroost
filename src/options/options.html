General

Cloud Sync (End-to-End Encrypted)

Sync your workspaces securely between your devices using client-side zero-knowledge AES-256-GCM encryption.

Master encryption passphrase All workspace data is encrypted with this passphrase before leaving your browser. Use at least 8 characters. It cannot be recovered if lost.
GitHub Personal Access Token (PAT) Needs gist scope to store encrypted data in a private secret Gist.
Remote Gist ID (optional) Leave blank on your first device to create a new Gist automatically; paste the ID on your other devices.

On-page workspace indicator

Optional. A visual anchor on web pages to identify workspaces, switch contexts, or save new windows. Turning it on asks the browser for access to all websites; turning everything off removes that access.
