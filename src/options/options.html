Sync your workspaces securely between your devices using client-side zero-knowledge AES-256-GCM encryption.

Master encryption passphrase All workspace data is encrypted with this passphrase before leaving your browser.
GitHub Personal Access Token (PAT) Needs gist scope to store encrypted data in a private secret Gist.
Remote Gist ID (optional) Leave blank on your first device to create a new Gist automatically; paste the ID on your other devices.
